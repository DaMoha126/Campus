# Étudia

Prototype d’une plateforme scolaire originale : espaces élève, parent, enseignant et administration, suivi pédagogique, devoirs, notes, emploi du temps, messagerie et progression.

## Ouvrir l’application

Ouvrez `outputs/campus/index.html` dans un navigateur. L’application est une démo locale et conserve ses données dans le navigateur.

## État du projet

Cette version est un prototype d’interface. Les comptes réels, la base de données, l’authentification, les permissions serveur et l’IA connectée à une API seront ajoutés dans les prochaines versions.
